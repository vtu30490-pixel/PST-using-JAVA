1. Functional Programming using map()
1.1 Build Array from Permutation - LeetCode
Problem
For every index i, create ans[i] = nums[nums[i]].
class Solution {
    public int[] buildArray(int[] nums) {

        int[] ans = new int[nums.length];

        for (int i = 0; i < nums.length; i++) {
            ans[i] = nums[nums[i]];
        }

        return ans;
    }
}
Example
Input:  [0,2,1,5,3,4]

Output: [0,1,2,4,5,3]
Logic
ans[0] = nums[nums[0]] = nums[0] = 0
ans[1] = nums[nums[1]] = nums[2] = 1
ans[2] = nums[nums[2]] = nums[1] = 2
Time Complexity: O(n)
Space Complexity: O(n)

1.2 Shuffle the Array - LeetCode
class Solution {
    public int[] shuffle(int[] nums, int n) {

        int[] result = new int[2 * n];

        for (int i = 0; i < n; i++) {
            result[2 * i] = nums[i];
            result[2 * i + 1] = nums[i + n];
        }

        return result;
    }
}
Example
Input:
nums = [2,5,1,3,4,7]
n = 3

Output:
[2,3,5,4,1,7]
Logic
nums = [x1,x2,x3,y1,y2,y3]

Result = [x1,y1,x2,y2,x3,y3]

2. Functional Programming using filter()
In Java, filter() is directly available in the Stream API. The following problems can be understood as filtering unwanted elements.

2.1 Remove Element - LeetCode
Simple Java Solution
class Solution {
    public int removeElement(int[] nums, int val) {

        int k = 0;

        for (int i = 0; i < nums.length; i++) {

            if (nums[i] != val) {
                nums[k] = nums[i];
                k++;
            }
        }

        return k;
    }
}
Example
Input:
nums = [3,2,2,3]
val = 3

Output:
2

Array becomes:
[2,2,...]
Logic
Only elements satisfying:
nums[i] != val
are retained.

2.2 Remove Duplicates from Sorted Array - LeetCode
class Solution {
    public int removeDuplicates(int[] nums) {

        if (nums.length == 0)
            return 0;

        int k = 1;

        for (int i = 1; i < nums.length; i++) {

            if (nums[i] != nums[i - 1]) {
                nums[k] = nums[i];
                k++;
            }
        }

        return k;
    }
}
Example
Input:
[1,1,2,2,3]

Output:
3

Array:
[1,2,3,...]
Logic
Keep the element only when it is different from the previous element.

3. Functional Programming using reduce()
Java's Stream API provides reduce() for combining multiple values into a single result. The following problems demonstrate the same reduction concept.

3.1 Maximum Subarray - LeetCode
Kadane's Algorithm
class Solution {
    public int maxSubArray(int[] nums) {

        int currentSum = nums[0];
        int maxSum = nums[0];

        for (int i = 1; i < nums.length; i++) {

            currentSum = Math.max(nums[i],
                                  currentSum + nums[i]);

            maxSum = Math.max(maxSum, currentSum);
        }

        return maxSum;
    }
}
Example
Input:
[-2,1,-3,4,-1,2,1,-5,4]

Output:
6
Maximum subarray:
[4,-1,2,1]

Sum = 6
Main idea
At every position:
Current Sum = maximum(nums[i], previous sum + nums[i])
Time: O(n)
Space: O(1)

3.2 Find the Highest Altitude - LeetCode
class Solution {
    public int largestAltitude(int[] gain) {

        int altitude = 0;
        int highest = 0;

        for (int g : gain) {

            altitude += g;

            highest = Math.max(highest, altitude);
        }

        return highest;
    }
}

[-5,1,5,0,-7]

Output:
1

4. Stream & Pipeline Processing
4.1 Group Anagrams - LeetCode
Java Solution
import java.util.*;

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {

        Map<String, List<String>> map = new HashMap<>();

        for (String word : strs) {

            char[] chars = word.toCharArray();

            Arrays.sort(chars);

            String key = new String(chars);

            map.computeIfAbsent(key,
                    k -> new ArrayList<>()).add(word);
        }

        return new ArrayList<>(map.values());
    }
}
Example
Input:
["eat","tea","tan","ate","nat","bat"]

Output:
[
 ["eat","tea","ate"],
 ["tan","nat"],
 ["bat"]
]
Important concept
For:
eat ? aet
tea ? aet
ate ? aet
All have the same sorted key, so they are grouped together.

5. Top K Frequent Elements - LeetCode
import java.util.*;

class Solution {
    public int[] topKFrequent(int[] nums, int k) {

        Map<Integer, Integer> frequency = new HashMap<>();

        for (int num : nums) {
            frequency.put(num,
                    frequency.getOrDefault(num, 0) + 1);
        }

        PriorityQueue<Integer> pq =
                new PriorityQueue<>(
                    (a, b) -> frequency.get(a) - frequency.get(b)
                );

        for (int num : frequency.keySet()) {

            pq.offer(num);

            if (pq.size() > k) {
                pq.poll();
            }
        }

        int[] result = new int[k];

        for (int i = k - 1; i >= 0; i--) {
            result[i] = pq.poll();
        }

        return result;
    }
}
Example
Input:
nums = [1,1,1,2,2,3]
k = 2

Output:
[1,2]
Logic
Frequency:
1 ? 3 times
2 ? 2 times
3 ? 1 time
Top 2:
1, 2

6. Stream API & Collection Processing
6.1 Java Deque - HackerRank
import java.util.*;

public class Solution {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int m = sc.nextInt();

        Deque<Integer> deque = new ArrayDeque<>();

        Set<Integer> set = new HashSet<>();

        int max = 0;

        for (int i = 0; i < n; i++) {

            int num = sc.nextInt();

            deque.addLast(num);
            set.add(num);

            if (deque.size() == m) {

                max = Math.max(max, set.size());

                int first = deque.removeFirst();

                if (!deque.contains(first)) {
                    set.remove(first);
                }
            }
        }

        System.out.println(max);
    }
}
Example
Input:
6 3
5 3 5 2 3 2

Output:
3
Main concepts
* Deque 
* ArrayDeque 
* HashSet 
* Sliding Window 

7. Java HashSet - HackerRank
The problem asks you to find the number of distinct pairs of strings.
Java Solution
import java.util.*;

public class Solution {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        Set<String> set = new HashSet<>();

        for (int i = 0; i < n; i++) {

            String first = sc.next();
            String second = sc.next();

            String pair = first + " " + second;

            set.add(pair);

            System.out.println(set.size());
        }
    }
}
Example
Input:
5
john tom
john mary
john tom
john harry
john mary
Output:
1
2
2
3
3
Explanation
HashSet does not allow duplicate values.
john tom   ? 1
john mary  ? 2
john tom   ? duplicate
john harry ? 3
john mary  ? duplicate
